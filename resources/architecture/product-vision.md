# Product Vision — DevByAI

## Your AI-powered open-source development companion

**Discover repositories. Understand code. Build features. Fix bugs. Contribute to open source.**

---

## Core Capabilities

| Capability | Description |
|------------|-------------|
| **AI coding chat** | Ask questions and generate code |
| **Coding agent** | Read and edit project files |
| **Contribution assistant** | Understand issues and prepare PRs |
| **Free model hub** | Choose from supported AI providers |

---

## Positioning

DevByAI is not just another AI chat window. It is a development companion that helps users move from discovering a repository to contributing back to open source.

The platform separates the **AI coding experience** from the **model providers**, enabling model swaps without application changes.

---

## Access Modes

| Mode | Who manages credentials | Quota source |
|------|------------------------|--------------|
| Shared free access | DevByAI platform | Provider free-tier limits |
| Bring Your Own Key (BYOK) | User | User's provider account |

Users should be able to choose their preferred access mode per session, not be forced into a global account setting.
