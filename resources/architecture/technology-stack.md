# Technology Stack

Reuse what you already have wherever possible. Do not force a completely different stack onto your existing project.

For a new implementation, this is a sensible stack:

| Layer | Recommendation |
|-------|----------------|
| Frontend | React / Next.js |
| Language | TypeScript |
| UI | Tailwind CSS |
| Code editor | Monaco Editor |
| Backend | Node.js with NestJS or Fastify |
| Database | PostgreSQL |
| ORM | Prisma or Drizzle |
| Background jobs | Redis with BullMQ |
| GitHub integration | GitHub App or OAuth |
| AI integration | Provider adapters |
| Code execution | Isolated Docker containers |
| Deployment | Container-based hosting |
