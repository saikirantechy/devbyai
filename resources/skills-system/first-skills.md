# First Official Skills

Start with **12 official skills**. Make them useful, focused, and tested.

| Skill | Category | Main Purpose |
|-------|----------|--------------|
| `frontend-builder` | Frontend | Build websites and interfaces |
| `react-developer` | Frontend | React applications |
| `nextjs-developer` | Frontend | Next.js applications |
| `backend-builder` | Backend | Backend services |
| `api-developer` | Backend | REST API development |
| `fullstack-builder` | Full-stack | Complete web applications |
| `database-architect` | Database | Database schema and queries |
| `ui-ux-designer` | Design | Interface and UX guidance |
| `debugging-expert` | Quality | Debug errors and fix bugs |
| `test-engineer` | Testing | Unit and integration tests |
| `devops-engineer` | DevOps | Deployment and CI/CD |
| `github-contributor` | Open source | GitHub issues and pull requests |

---

## Design Guidance

Don't make these twelve skills enormous. Each should have:

- A clear responsibility
- A focused workflow
- Tested instructions

Skills can reference one another when a task genuinely needs multiple specialties.
